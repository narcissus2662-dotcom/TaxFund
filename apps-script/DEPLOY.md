# วิธีเปิดใช้แอปกองทุนลดหย่อนภาษี (Google Apps Script)

ทำครั้งเดียว ใช้เวลาประมาณ 10 นาที ทำบน Mac จะง่ายที่สุด หลังจากนั้นเปิดแอปจากลิงก์ได้เลยทั้งบนมือถือและบนคอม

ข้อมูลตัวจริงอยู่ใน Google Sheet ชื่อ **กองทุนลดหย่อนภาษี (ข้อมูล)** ใน Google Drive ของบัญชีหลัก ซึ่งใส่ข้อมูลตั้งต้นไว้ให้แล้ว

## 1. เปิด Apps Script จาก Sheet
1. เปิด Sheet **กองทุนลดหย่อนภาษี (ข้อมูล)** ด้วยบัญชีหลัก
2. เมนู **ส่วนขยาย (Extensions)** แล้วเลือก **Apps Script** จะได้แท็บใหม่ที่มีไฟล์ `Code.gs`

## 2. วางโค้ด
1. ในไฟล์ `Code.gs` ลบโค้ดตัวอย่างทิ้งให้หมด แล้ววางเนื้อหาทั้งหมดจากไฟล์ **apps-script/Code.gs**
2. กด **+** ข้างคำว่า Files แล้วเลือก **HTML** ตั้งชื่อว่า **Index** (พิมพ์แค่ Index ไม่ต้องพิมพ์ .html)
3. ลบเนื้อหาตัวอย่างในไฟล์ Index แล้ววางเนื้อหาทั้งหมดจากไฟล์ **apps-script/Index.html**
4. กด **บันทึก** (ไอคอนแผ่นดิสก์ หรือ Cmd+S)

## 3. Deploy
1. มุมขวาบน กด **Deploy** แล้วเลือก **New deployment**
2. กดไอคอนเฟือง แล้วเลือก **Web app**
3. ตั้งค่า **Execute as = User accessing the web app** และ **Who has access = Anyone with Google account** (สิทธิ์เปิดแอปคุมด้วยการแชร์ Sheet ดูหัวข้อ "ให้บัญชีอื่นเปิดแอปได้" ด้านล่าง)
4. กด **Deploy** ครั้งแรกจะขึ้น **Authorize access** ให้เลือกบัญชีหลัก กด Advanced แล้วกด Go to (ชื่อโปรเจกต์) แล้วกด **Allow** (เป็นการอนุญาตให้สคริปต์ของคุณเองอ่านเขียน Sheet นี้)
5. คัดลอก **Web app URL** แล้วส่งให้ Claude

## 4. ใช้บนมือถือ
1. เปิด Web app URL ใน Chrome บนมือถือ
2. กดเมนูสามจุด แล้วเลือก **เพิ่มลงในหน้าจอหลัก** จะได้ใช้เหมือนแอป
3. ไอคอนเดิมของลิงก์ Netlify บนหน้าจอโฮม ลบทิ้งได้ เพราะลิงก์นั้นจะกลายเป็นหน้าแจ้งย้าย

## ใช้งานปกติ
- บันทึกรายการ ลบรายการ ตั้งเป้า ทุกอย่างถูกเขียนลง Sheet ก่อนแอปจะถือว่าบันทึกแล้ว
- ถ้าเน็ตหลุด รายการจะขึ้นว่า **ยังไม่ได้บันทึก** และด้านบนจะมีแถบเตือน แอปจะส่งให้เองเมื่อกลับมาออนไลน์
- ล้างข้อมูล Chrome หรือเปลี่ยนมือถือ ข้อมูลไม่หาย แค่เปิดลิงก์แล้วล็อกอินบัญชีหลัก

## ให้บัญชีอื่นเปิดแอปได้
- แอปทำงานด้วยสิทธิ์ของคนที่เปิด จึงเปิดได้เฉพาะบัญชีที่ได้รับแชร์ Sheet แบบแก้ไขได้ (Editor)
- จะเพิ่มคน: เปิด Sheet กด **Share** แล้วใส่อีเมล เลือก **Editor**
- จะเอาคนออก: เปิด Sheet กด **Share** แล้วลบอีเมลนั้น
- คนที่ได้รับแชร์จะเห็นและแก้ได้ทุกรายการ แอปยังไม่มีโหมดดูอย่างเดียว
- แต่ละบัญชีต้องกด **Authorize** ครั้งแรกที่เปิดแอป
- ห้ามตั้ง Execute as = Me คู่กับ Anyone with Google account เพราะใครมีลิงก์ก็เข้าถึงข้อมูลได้

## แก้โค้ดภายหลัง (ลิงก์เดิม)
1. วางโค้ดใหม่ทับใน Apps Script แล้วกดบันทึก
2. **Deploy** แล้วเลือก **Manage deployments** กดไอคอนดินสอ เลือก **Version: New version** แล้วกด **Deploy**
3. ห้ามกด New deployment ใหม่ เพราะจะได้ลิงก์ใหม่ ไอคอนบนมือถือจะยังชี้ลิงก์เก่า

## ถ้ามีปัญหา
- **ขึ้นแถบแดงเรื่องบัญชี Google:** บัญชีที่เปิดอยู่ยังไม่ได้รับแชร์ Sheet ให้เปลี่ยนไปใช้บัญชีที่ได้รับแชร์ หรือให้เจ้าของแชร์ Sheet ให้ แล้วเปิดแอปใหม่
- **ขึ้นแถบแดงว่าต้องอนุญาตสิทธิ์ใหม่:** เกิดได้หลังแก้โค้ดที่เปลี่ยนสิทธิ์ของสคริปต์ ให้ปิดแอปแล้วเปิดใหม่ แล้วกด Allow ทุกบัญชีต้องทำครั้งหนึ่ง
- **ขึ้นแถบเหลืองว่ามีรายการที่บันทึกไม่ได้และนำออกจากคิวแล้ว:** Sheet ปฏิเสธรายการนั้นเพราะข้อมูลผิดรูป ให้บันทึกรายการนั้นใหม่ให้ถูก
- **เปิดลิงก์แล้วขึ้นว่าไม่มีสิทธิ์:** แปลว่าบัญชีที่ใช้เปิดยังไม่ได้รับแชร์ Sheet
- **มี error อื่น:** แคปหน้าจอส่งให้ Claude
